# Politica di sicurezza

## Versioni supportate

Non sono state pubblicate release e il prodotto applicativo non è ancora implementato. Il repository contiene documentazione e automazioni. Non sono disponibili garanzie di sicurezza o di supporto per installazioni distribuite.

## Segnalare una vulnerabilità

Usare la [segnalazione privata di vulnerabilità GitHub](https://github.com/kairosci/aegis/security/advisories/new). Non aprire issue o discussioni pubbliche con dettagli della vulnerabilità.

Descrivere il componente e il commit interessati, i prerequisiti, i passaggi per riprodurre il problema, l'impatto osservato e un proof of concept non distruttivo. Rimuovere credenziali, token, dati personali e informazioni appartenenti a terzi. Non allegare dati reali o segreti.

La comunicazione e l'eventuale coordinamento della divulgazione avvengono nel report privato GitHub. Non è pubblicato un tempo garantito di presa in carico o correzione. Non inviare la segnalazione tramite issue, pull request o canali pubblici.
